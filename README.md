* **Banco de Dados:** PostgreSQL 16 · MySQL 8 · Prisma ORM · Eloquent · Redis (Cache & Invalidation)
* **DevOps & Engenharia:** Docker · GitHub Actions (CI/CD) · Git Flow · Transações ACID · RBAC
